## 2. Part A: naturalistic, the headline set

- **Who:** classmates who did not contribute on 30 Oct. New people avoid one person's style dominating, and avoid anyone who has seen answers.
- **How:** exactly as before. Hand out `docs/benchmark/classmate-questions.md` (printable: `docs/pdf/Airlume_Classmate_Questions.pdf`) unchanged. Show no app, no form, no examples beyond what the sheet already says.
- **Target:** 60 to 100 questions, from about 4 to 5 people. At n = 62 a 90% result has a Wilson interval of about ±7.5 points; at n = 100 it is about ±6.
- **Into the repository:** type them into `airlume/eval/benchmark/classmate-raw-2026-11-<dd>.jsonl` in the same format as `classmate-raw-2026-10-30.jsonl`, with ids `d001` onward, contributor letters continuing from the first batch, and `lang` `en` or `ur-Latn`.
- **E4 user-study questions**, when the study runs, are kept as a separate labelled supplement and never pooled into Part A.

## 5. Score once

After adjudication, the gold sheets are frozen and scored a single time per model:

```
REFERENCE ONLY: the order of the final steps, once the gold sheets exist
1. check each sheet:      python scripts\check_annotation.py <sheet>
2. agreement:             python scripts\annotator_agreement.py <kiran-sheet> <tehreem-sheet>
3. score, once per model: python scripts\score_benchmark_v1.py <gold-part-A> --model openai/gpt-oss-120b
                          python scripts\score_benchmark_v1.py <gold-part-B> --model openai/gpt-oss-120b
4. secondary finding:     python scripts\annotator_agreement.py classmate-raw-2026-10-30-annotated-DRAFT-by-claude.csv <kiran-sheet-for-the-62>
```

Step 4 needs Kiran's labels for the original 62 (the blank `classmate-raw-2026-10-30-annotated-kiran.csv` already exists). It is reported as model-versus-human agreement, never as inter-annotator agreement.

Report:
- the scope gate with a Wilson interval;
- per-field counts, then intervals, and no claim for any field with n under about 10;
- the language split with a Newcombe interval. At these sizes only a gap of about 20 points or more can be told apart from zero.
