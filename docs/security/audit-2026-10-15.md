Residual risks
- A GitHub fine-grained token (Actions: write, this repository only, expires 13 Jan 2027) lives in cron-job.org to trigger the collector (installed 15 Oct 12:30). Compromise of that service could start workflow runs, nothing more; the token cannot read code or push.
- Groq daily budget can still be exhausted by legitimate use (benchmark runs); the app then falls back to the rule-based router and says so.
