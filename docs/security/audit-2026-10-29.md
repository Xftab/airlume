## Bandit results

6 medium-confidence findings, all in `pipeline/store.py` — f-string SQL with column names from `_ALLOWED_METRICS` / `_ALLOWED_AGG` (hardcoded sets of 3 and 5 strings). User values always go through `?` parameters. **All 6 are false positives.**

## pip-audit results

- **Pillow 12.3.0**: 39 known vulnerabilities (CVE-2026-112891 through CVE-2026-112900, PYSEC-2026-4326 through PYSEC-2026-4343). Fix: upgrade to >= 13.0.0.
- All other pinned packages: clean.

## Actions before public deploy

1. **Upgrade Pillow** — add `Pillow>=13.0.0` to requirements.txt (or pin 13.0.0). Pillow is a transitive dependency of Streamlit; pinning it explicitly forces the safe version.
2. **Rotate exposed keys** (Item 4) — GitHub fine-grained token and Groq key. User action, still pending.
3. **Minor**: either exempt the hardcoded header from the `unsafe_allow_html` test, or replace it with `st.title()` + `st.caption()` to keep the test honest.
