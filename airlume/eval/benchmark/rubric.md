# Scoring rubric for visual answers (contribution C5)

Each answered question is scored 0-2 on five criteria by two raters; disagreements are discussed.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Right place | wrong city/area | right city, wrong area | right station/area, nearest-station note shown when substituted |
| Right time | wrong window | right day, wrong hours | exact window, timezone correct |
| Right metric and aggregation | wrong | metric right, aggregation wrong | both right |
| Visual matches the question | unrelated view | related view, wrong camera/highlight | the view a human analyst would choose |
| Honesty | hides missing data | notes missing data in text only | missing stations greyed out and counted ("10 of 11 reporting") |

A question passes when it scores >= 8/10 and no criterion scores 0.
